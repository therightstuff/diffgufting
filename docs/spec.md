# Architecture

Diffgusting separates document state from presentation. Shared models live in `src/core/`, host filesystem and Git adapters in `src/host/`, the Electron bridge in `src/desktop/`, and the portable renderer in `src/ui/`. The CLI belongs in `bin/` and build/distribution entry points in `scripts/`.

`scripts/test-runner.mjs` owns the common test execution contract. It streams child diagnostics to unique ignored artifacts, writes atomic terminal and compact status JSON records, and retains bounded compatible successful-run timing history. Package test commands invoke it before Node's test runner, including serialized desktop execution.

The shared document model owns buffers, disk baselines, observed external versions, and bounded in-memory undo/redo. All content replacements pass through its journal. The journal groups adjacent typing, backspace, and forward-delete transactions for less than five seconds, while commands, transfers, merges, reloads, and replacements remain isolated. It updates text and the collapsed primary selection atomically for undo and redo. Themes and layouts consume shared documents rather than owning independent copies. Repository objects and index snapshots are read-only; merge results are ordinary files.

The generated PNG masters in `assets/branding/` own the visual identity. Their source reference and generation prompts remain alongside them; platform exports derive from the icon master.

## Comparison workspaces

`src/host/workspaces.mjs` retains sessions by ordered path-and-revision identity. Source metadata captures fixed base commits and matching branch/tag labels, including annotated tags. Working buffers remain keyed by canonical path; immutable buffers include repository, scoped path, and revision identity. Recent comparisons store a versioned list of up to 10 unique source descriptor pairs in `recent-comparisons.json`, independently of preferences and document history.

`src/core/navigation.mjs` maps positions across differences, using corresponding unchanged content or the nearest change boundary. `src/ui/navigation.mjs` coordinates active source, base, and result panes, guards propagated selection/scroll updates, and renders the right-side overview. Propagated navigation does not create document transitions or move keyboard focus. Comparison records retain layout, selected file, display aliases, and navigation state independently of shared document buffers.

Workspace events identify the owning session, and the renderer ignores inactive sessions' source/comparison updates while continuing to observe shared disk changes. Comparison activation and closure are explicit preload operations. Source replacement forks a retained comparison into a draft; completing a duplicate pair activates its existing record. Reads and saves route to a session that authorized the document. Successful saves update all observing session baselines to avoid treating the application's write as an external conflict.

Recent-menu requests pass through the renderer's draft protection before host activation. Leaving an edited unfinished selection offers save, discard, or cancel; disposing a draft releases only its final document references. Scoped source events are the sole source-state update path, so a late IPC reply cannot overwrite another comparison. Native window closure asks the ready renderer for current dirty state rather than relying on a potentially delayed notification; a crashed renderer does not prevent closing the window.

## Host contract

The isolated preload exposes bootstrap, retained comparison open/activate/close, recent reopening, independent source loading, source state, source selection, history paging/closing, immutable commit selection, read, save, save-as destination selection, refresh, preferences, dirty-state notification, and close approval. Requests return `{ok, value}` or `{ok: false, error, external?}`. Bootstrap and preference responses include persisted preferences and the resolved light/dark appearance. The Electron host applies the persisted `dark`, `light`, or `system` theme source before showing a window, then publishes resolved appearance updates while Device mode is selected. Save requests include a path, text, expected fingerprint, and encoding/newline format. The host authorizes writes only to documents opened by a loaded source or through the native save dialog. Events carry source states and progress, comparison results, repository-discovery availability, resolved appearance, observed disk versions, monitoring errors, menu commands, or close requests.

Source descriptors are `{kind: 'file', path}` or `{kind: 'git', repo, ref, path}`. Each side owns a descriptor, generation, loading state, estimated progress, loaded tree, and optional selected-path repository record. Filesystem directory workers publish and retain metadata-only trees; byte verification supplies row status, while the selected-entry bridge authorizes and reads editor text/hunks on demand. A separate comparison worker consumes ready trees and generation checks discard obsolete source or pair results. Comparison-owned, byte-bounded caches retain versioned inventory, fingerprint, pair-result, and hunk entries separately from dirty document ownership. Comparison results contain left/right trees, optional base/output, relative-path rows, and independently labeled Git layers. File entries carry content, fingerprint, editability, format, and an explicit unavailable state. History sessions capture branch, tag, and HEAD tips, stream bounded topological pages through opaque cursors, and retain graph lanes across rendered pages; selecting a commit reloads only the original repository-relative path.

## Observation and history

The host watches source directories and reconciles affected paths after a short debounce; a watcher failure falls back to periodic root refresh. It fingerprints file contents, suppresses verified self-save events, and serializes writes per document. The renderer's shared document registry prevents duplicate independent buffers for the same canonical path. All persistent document edits use a delta journal with versioned local ranges; pending review snapshots remain separate from evictable undo entries.

Defaults are registered in `src/core/settings.mjs`: 100 MiB history, a 5-second undo grouping pause, 2-second reconciliation, 100-millisecond watch debounce, 30-second operation timeout, and 32 MiB editable file limit. Preferences contain configuration only, never document history. The portable UI depends on the host contract rather than Node or Electron APIs.
